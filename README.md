## ESP32 智能存取快递柜控制系统

这是一个基于 ESP32 的智能存取快递柜控制系统，集成了强制门户（Captive Portal）、GUI 交互、网络通信、存储管理等功能，可用于毕业设计或实际项目开发。

## 项目结构

plaintext

├── APP/ # 应用主逻辑入口

├── CAMEAR/ # 摄像头模块（可选，用于取件码验证或监控）

├── MQTT/ # MQTT 客户端，用于与云端/后台通信

├── WIFI/ # WiFi 管理（AP/STA 模式切换、连接管理）

## 核心功能

1.  \***\*强制门户（Captive Portal）\*\***
2.  - 设备启动后自动开启 WiFi AP，用户连接后自动弹出认证页面。
    - 支持 Android/iOS/Windows/Firefox 等多平台的强制门户检测。
    - 用户可通过网页设置 WiFi 连接、输入取件码或进行身份验证。
3.  \***\*GUI 交互界面\*\***
4.  - 基于 LVGL 实现的嵌入式图形界面，支持触摸操作。
    - 显示柜格状态、取件码输入、操作提示等。
    - 可通过 GUI Guider 快速修改和扩展界面。
5.  \***\*网络通信\*\***
6.  - \***\*WiFi 管理\*\***：支持 AP+STA 双模，可灵活切换，保证网络连接稳定。
    - \***\*MQTT 通信\*\***：与云端服务器或后台管理系统通信，上报柜格状态、接收取件指令。
    - \***\*HTTP 服务\*\***：提供网页端操作接口，支持远程管理。
7.  \***\*硬件控制\*\***
8.  - \***\*WS2812 彩灯\*\***：用于指示柜格的占用 / 空闲 / 异常状态。
    - \***\*摄像头（可选）\*\***：支持取件码扫描或人脸识别（需额外硬件）。
    - \***\*SD 卡存储\*\***：用于存储操作日志、用户记录或临时图片。

## 快速开始

### 环境要求

- ESP-IDF v5.x 或以上版本
- LVGL 图形库
- 支持 ESP32 的开发板（如 ESP32-S3）及配套硬件（显示屏、WS2812、SD 卡等）

### 编译与烧录

1.  克隆或下载本项目到本地。
2.  使用 ESP-IDF 命令行工具进入项目目录。
3.  执行 `idf.py set-target esp32s3`（根据你的芯片型号调整）。
4.  执行 `idf.py menuconfig` 进行必要的配置（如 WiFi SSID、MQTT 服务器地址等）。
5.  执行 `idf.py flash monitor` 编译、烧录并监控串口输出。

## 注意事项

- 首次使用前，请确保硬件连接正确，特别是显示屏、WS2812 和 SD 卡。
- 强制门户功能依赖于正确的 DNS 和 HTTP 重定向配置，请确保 `Captive Portal` 和 `HTTP` 模块配置正确。
- MQTT 通信需要配置正确的服务器地址和凭据，否则无法与后台通信。
